This repo is a collection of various projects in the graphics programming space that I use for learning, creating, or experimenting in my spare time. Most are unfinished small game projects. All code was written from scratch with some minimal libraries (a few stb libs for texture and font loading. My game code started with raylib, but has switched to a native win32 + opengl). All code is written in the C programming language.

AI use: to the best of my memory there is a low single digit percentage of AI generated code (unit tests, a few macros, and some OpenGL settings). AI was occasionally consulted when I didn't know how to do something. The rest has been hand typed by myself.

In many of these projects I've tried experimenting with different styles or approaches to coding, so quality varies quite a bit. The main goal wasn't the code, it was to create and have fun :)
