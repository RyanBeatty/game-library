Blank project that is cloneable with basic boilerplate structure already set up.


* ui text box
* table/grid layout. really basic


* explanation of layout algorithm
* Making a Window will specify its size in absolute pixel sizes
* making a row is fit to parent. this happens naturally from parent window having absolute pixel size
* each button within the row is on same level. Since all on same level and all fit to parent, they all get
100% of parent width.
* When resolving violation, will subtract proportional size from each child of the 
row so that its all equal.
